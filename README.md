# Real-Time AI-Powered Flood Prediction and Alert System

## Team Name
Nova Squad

## Problem Statement
Floods cause significant damage to life and property due to delayed warnings and inefficient emergency response. Our project aims to provide an AI-powered solution that predicts flood risks in real time and alerts both citizens and municipal authorities.

## Project Overview
The Real-Time AI-Powered Flood Prediction and Alert System uses weather forecasts, water-level data, historical flood records, and AI-based analysis to predict flood-prone areas. The system provides early warnings, live flood maps, safe navigation routes, and a municipal dashboard for efficient disaster management.

## Tech Stack

- Frontend: React
- Backend: Flask (Python)
- Database: Firebase Firestore
- AI/ML: TensorFlow
- Maps: Google Maps API
- Cloud: AWS

## Key Features

- Real-time flood prediction
- Live flood risk visualization
- Citizen flood reporting with photo and GPS
- Municipal authority dashboard
- Emergency alerts and notifications
- Safe route navigation
- Weather forecast integration
